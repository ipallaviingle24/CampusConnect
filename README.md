# CampusConnect – College Event Discovery Platform 🎓

**Discover. Connect. Participate.**

CampusConnect is a college event discovery platform designed to make campus life more accessible by bringing event information together in one centralized, user-friendly interface.

Students often miss workshops, competitions, technical events, and college activities because announcements are scattered across WhatsApp groups and other communication channels. CampusConnect aims to simplify event discovery and help students stay connected with opportunities happening on their campus.

---

## 📌 Problem Statement

Students frequently miss important college events because information is distributed across multiple communication channels. Finding relevant events and keeping track of upcoming activities can be difficult and time-consuming.

## 💡 Our Solution

CampusConnect provides a centralized platform where students can discover campus events, explore college fests, view event details, browse a calendar, and bookmark events they are interested in.

The goal is to make discovering and participating in campus activities easier and more convenient.

---

## ✨ Key Features

* **🏠 Home Page:** Explore campus activities through a centralized interface.
* **📅 Event Calendar:** Browse events and keep track of upcoming activities.
* **🔍 Event Discovery:** Explore available college events in one place.
* **🎉 College Fests:** Discover college festivals and explore their details.
* **📄 Event Details:** View information about individual events.
* **🔖 Bookmarks:** Save interesting events for quick access.
* **📱 User-Friendly Interface:** Navigate campus activities through a structured and intuitive design.

## 🧠 Design Thinking Approach

This project was developed as part of our Design Thinking FA2 project.

Our approach focuses on understanding student challenges and designing a practical, user-friendly solution.

### 1. Empathize

Understand how students discover college events and identify difficulties caused by scattered announcements and excessive notifications.

### 2. Define

Identify the core problem: students miss campus opportunities because event information is distributed across different communication channels.

### 3. Ideate

Explore solutions for centralizing event information and simplifying event discovery.

### 4. Prototype

Develop an interactive web application with event listings, fest exploration, event details, calendar navigation, and bookmarking functionality.

### 5. Test

Evaluate the prototype with users, collect feedback, and identify opportunities to improve usability and navigation.

## 🚀 Getting Started

Follow these steps to run CampusConnect locally.

### Prerequisites

* Node.js
* npm
* Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ipallaviingle24/CampusConnect.git
```

**2. Navigate to the project directory**

```bash
cd CampusConnect
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, typically:

`http://localhost:5173`
